# 🐎 特码智能收单与吃码风控系统 Pro v2.0

基于原版 Excel 宏工作簿（`马年(1)_已修复.xlsm` / `马年(1).xlsm` / `原始文件.xlsm`）全量重构的现代化面向对象桌面应用程序。去除原版复杂的宏环境依赖与机器码注册锁限制，内置本地 **SQLite 数据库**、**1,955+ 智能识别词库**、**多盘口/多客户实时风控与飞单计算器**，并提供全套自动化测试与跨平台打包部署服务。

---

## ✨ 核心特性一览

1. **面向对象 (OOP) 四层清晰架构**
   - **领域模型层 (`src/domain/`)**：封装 `AppConfig`、`RegionConfig`、`ClientProfile`、`ParsedBetItem`、`OrderRecord`、`RiskItem`、`BookmakerRecord` 等核心实体，以及支持 12 生肖年份动态轮转的 `NumberAttributeEngine`。
   - **数据持久层 (`src/database/`)**：采用本地 `SQLite` 数据库（WAL 高并发安全模式）+ 仓储模式 (`Repository Pattern`)，支持一键备份、恢复、压缩与历史快照存档。
   - **业务服务层 (`src/services/`)**：
     - `WeChatParserService`：完整复刻并增强原版微信/QQ多格式报单识别（支持各肖、各号、多头多尾、波色单双、区间 `1到25`、总金额平摊 `共`、反码、一键负数、键盘盲打极速录入、自定义文字替换），**经原表 29 笔真实历史订单验证 100% 零误差匹配**。
     - `RiskAndEatService`：实时计算 1–49 号风险盈亏值（$\text{风险值} = \text{总收单} \times (1 - \text{回水}) - \text{单号押注} \times \text{赔率}$），支持按平均吃码、**按最大允许亏损额二分查找反推最佳吃码上限**、按比例吃码/上报、按指定号码/属性吃码上报，以及多上庄（`上庄张`~`上庄吴`）报单归档与一键撤回。
     - `SettlementService`：支持订单入库、双击撤单并自动扣回对应客户 1–49 号统计金额、开奖特码对奖算账、中奖号码红色高亮核对。
     - `ExcelMigrationService`：支持随时导入原版 `.xlsm/.xlsx` 表格数据，或将当前盘口汇总榜、分人算账单、订单明细导出为精美排版的 `.xlsx` 报表。
   - **现代化前端交互层 (`src/ui/`)**：提供亮色 (`Light`) 与暗色 (`Dark`) 一键切换主题，五大核心工作台标签页布局直观清晰。

2. **开箱即用 & 历史数据零损迁移**
   - 首次启动自动将原 Excel 中的 **1,955 条识别关键字**、**3 大默认盘口（新澳门、香港、旧澳门）**、**150+ 客户配置** 及 **29 笔历史明细订单** 初始化至 `data/lottery_system.db`。

3. **全方位用户自定义配置**
   - 可随时切换**农历本命年生肖（鼠~猪）**，1–49 号生肖归属自动实时重算；
   - 自定义客户专属赔率与回水比例、自定义新增识别关键字、自定义文字替换规则、自定义属性标签号码组合。

## 🚀 快速使用指南

### 方式一：直接双击运行独立 `.exe` 程序（推荐）
直接双击项目根目录或 `dist/` 目录下的：
- `特码智能收单风控系统Pro.exe`
- 本地数据库自动保存在同级目录下的 `data/lottery_system.db`。

### 方式二：从 Python 源码运行
```powershell
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动主程序
python main.py
```

## 🧪 自动化测试与一键打包部署

项目内置完整的 `pytest` 自动化测试套件（涵盖领域模型、中文金额转换、原表 29 笔真实微信订单回归测试、二分风控吃码反推、开奖结算、UI 端到端集成测试）：

```powershell
# 运行全量单元测试与 UI 集成测试
pytest -v

# 运行一键自动化测试 + 离屏冒烟自检 + PyInstaller 独立 exe 打包流水线
python scripts/build_exe.py
# 或使用 PowerShell 脚本:
./scripts/build_exe.ps1
```

同时内置 GitHub Actions 跨平台 CI/CD 工作流 (`.github/workflows/ci_cd.yml`)，支持在 **Windows / macOS / Linux** 三大平台自动执行测试与构建发布。
